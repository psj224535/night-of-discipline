# NIGHT OF DISCIPLINE

친구 다섯 명이 서로 다른 운동 목표를 정하고, 한 달 동안의 변화와 월간 내기 결과를 함께 기록하는 반응형 웹앱 MVP입니다.

## 실행 방법

Node.js 20 이상이 필요합니다. nvm을 사용한다면 저장소의 `.nvmrc`에 맞춰 `nvm use`를 실행하세요.

```bash
npm install
npm run dev
```

프로덕션 빌드와 테스트:

```bash
npm run build
npm test
```

## 주요 기능

- **스쿼드 대시보드**: 참가자별 목표, 정규화 달성률, 최근 업데이트, 연속 기록, 응원을 한눈에 확인
- **서로 다른 목표 지원**: 수치형(증가/감소), 체크포인트형, 완료형 목표를 같은 0–100%+ 기준으로 표현
- **개인 기록**: 체중·골격근량·체지방률 요약, 변화 그래프, 목표 상세, 월간 내기와 인바디 기록이 합쳐진 타임라인
- **월간 내기**: 예정·진행 중·완료 라운드, 참가자별 목표, 기간, 보상, 최종 성공 여부 표시
- **입력과 수정**: 인바디 기록 추가, 목표 현재값·체크포인트·완료 여부 수정, 프로필 전환, 응원 반응
- **로컬 저장**: 백엔드 없이도 모든 변경을 브라우저 `localStorage`에 저장하고 데모 초기화 가능
- **반응형 UI**: 모바일 하단 내비게이션과 데스크톱 대시보드 레이아웃 제공

## 데이터 모델

핵심 상태는 `Participant`, `Goal`, `BodyRecord`, `Challenge`로 구성됩니다.

- `Participant`: 프로필, 현재 목표, 최근 활동, 인바디 기록, 응원 수
- `Goal`
  - `numeric`: 시작값·목표값·현재값·증감 방향
  - `checkpoint`: 단계 목록과 완료 단계 수
  - `completion`: 이벤트/시합의 최종 완료 여부
- `BodyRecord`: 날짜별 체중·골격근량·체지방률·메모
- `Challenge`: 라운드 기간, 상태, 참가자, 개인별 목표 스냅샷, 최종 결과

수치형 목표의 달성률은 증가 목표의 경우 `(현재값 - 시작값) / (목표값 - 시작값)`, 감소 목표의 경우 `(시작값 - 현재값) / (시작값 - 목표값)`으로 계산합니다. 100% 초과 달성도 보존하며, 시각적 막대만 100%에서 제한합니다.

## 향후 백엔드 연동

현재 `AppState`와 브라우저 저장 계층을 API 저장소로 교체하기 쉽게 분리했습니다. 실제 서비스에서는 다음 순서로 확장할 수 있습니다.

1. 이메일/소셜 로그인과 그룹 초대
2. PostgreSQL 기반 사용자·그룹·목표·측정 기록·챌린지 테이블
3. REST 또는 tRPC API를 통한 기록 동기화
4. 응원/댓글 실시간 알림과 이미지 첨부
5. 인바디 CSV·헬스 플랫폼 연동 및 권한별 공개 범위

## 기술 스택

React 18, TypeScript, Vite, Lucide React, Vitest. 외부 폰트나 이미지에 의존하지 않습니다.
